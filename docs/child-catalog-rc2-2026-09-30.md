# Native child catalog adapter (dsh 0.2.0-rc.2)

The published `subagents.list` endpoint lists provider names, not child Sessions. The terminal compatibility adapter now reads the native `SubagentRuntime.listChildren(parentSessionId, signal)` Host method and validates its result using the terminal catalog schema. Parent availability comes from Agent residency. Stable Cordis service and parent identities are checked before and after the read; cancellation and malformed rows reject rather than grant navigation. No parent is warmed for this read.

The existing client direct-parent address, generation and readiness gates remain. Ten regressions cover real Cordis contextual proxies, cancellation, service/Agent replacement, malformed catalog rows, cold residency and the actual vendored SessionManager catalog/address route. Eight related suites pass 73 tests. Actual unmodified Host child creation, PTY navigation into hot/cold children and parent return remain pending independent review of this commit.

Correction after actual packaged review: `listChildren` returns durable `{id, createdAt, mode, label}` identities, not terminal presentation rows. The first adapter incorrectly assumed terminal rows and did not close P2. The corrected adapter uses native `listDescendants`, retaining exactly `parentId === requested parent` and `depth === 1` rows. Native code supplies activity, hasChildren and diagnostics; the adapter does not infer them from durable identities. Inconsistent parent/depth rows reject. The prior 73-test result is explicitly not evidence of real child navigation.

Independent parent-delivered review of `5bd6d3b` on official rc.2/no shim closes the original navigation P2: actual hot and cold nonresident children with legal history open, Escape returns to parent and exit is zero. The follow-up P3 was display-only: after hot→parent→cold, child content was correct but breadcrumb used the tree's prior selected hot label. Surface now resolves `agentTree.node(targetSessionId)`; missing nodes fall back to the target ID. Actual AgentTree two-child identity regression and 41 related Surface/child/exit tests plus typecheck pass. Actual same-package breadcrumb recheck remains pending.
