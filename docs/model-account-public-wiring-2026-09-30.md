Configured values are labelled manual, not certified discovery or server validation. No discovery or model inference request is made to populate this view.

The existing `/attach` image path checks this evidence before opening the file. Declared text-only input refuses it; unknown supports the existing image intake with an uncertainty notice. Login takes the actual port of the already listening official HTTP webServer. Missing listener disables login; no websocket origin or guessed port is substituted. The supplied browser URL is validated by the account controller and can be copied to complete browser sign-in. Confirmed external browser opening remains part of D's link integration.
