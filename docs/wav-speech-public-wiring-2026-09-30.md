# Public WAV speech entry (F083)

`/speech wav` is registered in the terminal command catalog and reaches D's controller through the existing same-process management bridge and exact official Gateway descriptors. Missing experimental speech service stays unavailable; opening the command does not install, enable or prepare anything.

To opt in, install/enable the official `@deepseek-ai/dsh-experimental-voice-input-bundle@0.2.0-rc.2` with the native Profile plugin manager. Its published patch owns SpeechToText, SenseVoice dataRoot and the API; the terminal consumes the Host API, not the bundle's React input component. Cached-resource inspection at provider activation is not a model download. `/speech wav` offers explicit preparation with actual Host resource estimates and advertised sources. The protocol has no hard download-storage cap, and preparation is shared Host work. Closing the page stops observation only; cancelling shared preparation needs its separate explicit confirmation.

Local input is an explicitly selected 16kHz mono PCM16 WAV, bounded to at most 4MiB/120s and any smaller Host limits. The original file is retained; only an owned private temporary snapshot is removed. Transcription needs consent, and its result gets a separate review and insertion consent. Insertion reuses TerminalInputExtensions' original opaque selection/caret capture and monotonic draft revision, preserving single undo and Session/generation isolation. It never calls Session prompt/submit. No implicit conversion, microphone recording, format fallback or audio/video receipt claim is made.
