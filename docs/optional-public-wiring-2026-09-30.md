# Optional public routes: source integration evidence

The fixed integration branch mounts package-owned same-process ports alongside its existing Settings/Session bridge. No optional plugin is installed or activated by opening a view.

- `/mcp resources` and the `/mcp` resource row use the three shared tools through native ToolRuntime.execute, with the exact existing Agent and its original cancellation signal. Tool visibility is checked again at dispatch. Canonical permission-filtered values are read; rendered tool text is not parsed as an API. The configured server name is entered explicitly because no public resource-server inventory exists.
- `/team` exposes the existing experimental membership/roster/task board and normalized Lead journal. Membership and exact Agent/service identities are checked around the journal read. Cold Agents are never resumed. The native inspect prefix is explicitly treated as incomplete mailbox coverage, so absent delivery evidence remains unknown. No message/task mutation or second mailbox runner exists.
- `/schedules` uses mounted direct descriptors and the native Gateway for catalog/list/history/update/delete. Original Session bindings and native expected-record comparison are retained. There is no invented pause, create or activation action. Team/Schedule directory entries are withheld when the necessary capability is unavailable; typed routes explain the missing capability.
- `/descendants` (also `/subagents descendants`) reads the native recursive Host catalog. Opening a row refreshes only its direct-parent catalog, confirms the exact child id and mode, and then uses existing child-view navigation. The frozen return owner is the currently viewed root, distinct from a nested child's direct parent. Selection/connection changes or cancellation during preparation prevent opening; one-shot children remain read-only. Existing child views must close before another descendant can open.

Selection changes, disconnects and Host description changes invalidate observations. A controller is bound to the Session selected when opened; switching away cannot redirect its port to another Session, and switching away/back changes its generation. Native unary reads are bounded observations, not claims of server-side cancellation.
