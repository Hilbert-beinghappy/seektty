# Host file public wiring (F062/F117)

Fixed integration branch `codex/remaining-terminal-adapters`; frozen earlier candidate17770b9 is preserved. This stage consumes S02's afc79d7 modules, without modifying their adapter/observer during independent review.

`/files` now exposes Host workspace directory browsing and regular-file text/binary views; produced-file and file context view/copy actions use the same scoped Host ports. Recorded artifacts receive all five ports. Local file uploads remain client reads followed by native receipt submission. No Host reference is read through client `node:fs` or resolved against client cwd.

The mounted native operator surface resolves the official `workspaceFileScope` lookup, then calls the Host `fs.resolve` and `processPath`. It confirms Session identity/root and mounted lookup/backend/Gateway identity before publishing transient canonical root metadata. This does not activate a cold Agent, create a permission policy or pretend these Agentless Remote methods use tool approval. Native Gateway OperatorPeer and filesystem backend authority remain unchanged. Missing scope, descriptor, backend or canonical root blocks dispatch. Cancellation returns promptly and late roots cannot publish.

Text/stat/bytes/list/changes use the official adapter. Watch unsupported remains manual. Views close their owned observation; scope changes invalidate reads. External open uses the existing native `session/openWorkspacePath` verifier only when the Host filesystem has a desktop mapping; remote/unmapped paths are disabled. Copied paths are confirmed canonical Host metadata, and clipboard rejection does not report success.

Containment is a terminal reference policy over the published path-based Host reader. Canonical preflight/version checks are **best effort**, not an atomic confinement guarantee: a concurrent backend path/symlink replacement can still race the official reader. No claim to fix the native TOCTOU is made. S02's strict-capability and cleanup review fixes are integrated (04ad001/1f794e99): dispose and bounded iterator return are independently attempted; unconfirmed cleanup blocks a successor. Explicit strictConfined refuses without actual provider atomic evidence. Do not offer strict-confined operation without real provider atomic evidence.
