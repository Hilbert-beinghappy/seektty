# Fetch URL public integration

The rendered collapsed header keeps scoped Host call/result presenter evidence and its known inserted title range. Renderer source offsets identify exact wrapped title fragments; the URL rectangles are disjoint from the remaining toggle cells. Redirected result URLs do not silently replace the displayed original URL. Unknown/unsafe presenter titles remain ordinary tool toggles.

Full mode provides a separate URL click and right-click `open-url` / `copy-url` menu. Completed paired unmodified left clicks open once; drag, modified, middle and repeated clicks do not dispatch. Tool Enter still toggles. `/fetch-url` opens the keyboard menu for the focused tool; copy-url is independent of generic selected-text Copy. Native scrollback belongs to the terminal and receives no invented hit coordinates; explicit native tool focus exposes the same keyboard menu using current scoped presenter evidence.

The actual system browser handoff accepts validated HTTP(S) URLs without embedded credentials, uses one argv argument with no shell, filters inherited environment, observes the launcher exit, and never retries. Missing launchers disable Open while Copy remains independent. Clipboard completion/errors are awaited. Browser handoff cannot guarantee page load or revoke an already dispatched browser action. Surface close, selected Session loss and connection generation changes invalidate observations. Recorded artifact URL menus also receive this actual opener when mounted.

Source validation uses Node 24 with fresh HOME/XDG/DSH_HOME and no real keys/history/model requests. Eight files, 181 tests and typecheck passed (`.artifacts/fetch-title-public-wiring.log`), including actual Transcript wrapping at 80/24/10 columns, Unicode in full/native modes, disjoint toggle cells, pending clock-only repaint stability, redirect labels, unavailable opener, changed Session/frame, keyboard copy and legacy Enter toggle, asynchronous clipboard error, and mocked system launcher failure. No real browser was opened. The first new native test exposed that scrollback has no resident hit map; the final implementation explicitly supplies native keyboard access instead. These source tests are not packaged PTY acceptance.

Still required on the final immutable package: real full-mode pointer press/release, narrow terminal resize/scroll and stale frames, right-click/keyboard menus, native keyboard focus, clipboard refusal, lifecycle closure, and safe opener dispatch with a test-only subprocess recorder. Keep real browser/network effects disabled during acceptance. Default stock boot and the optional routes previously verified at earlier SHAs must be repeated for the final package.
