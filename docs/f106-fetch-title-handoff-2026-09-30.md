## Evidence and implemented behavior

Untouched published dsh `0.2.0-rc.2` `dsh-tool-web/lib/index.js:650-656,712-722` produces pending `{card:'generic', kind:'fetch', title:args.url, rawInput:args.url}` and result `{card:'web', kind:'fetch', title:args.url, url:meta.url, statusCode, truncated}`. `meta.url` is the final redirect URL. SeekTTY `host/tool-presentation.ts` obtains these from the scoped registered `ctx.tools.get(..., scope).presentCall/presentResult`; that is the evidence source. Arbitrary tool content/meta/args carrying similar fields must never be supplied to this helper as presenter evidence.

`fetchTitleUrl(title, scopedPresentations, safeArtifactUrl)` admits only an exact matching presenter URL and a safe HTTP(S) href. The displayed raw spelling is retained for cell mapping; the action href uses the existing validator's canonical spelling. A result redirect different from its displayed original title is not hidden behind that title. A retained matching call presenter can still supply the visibly named original URL. No tool-name fallback, regex URL discovery, fetch, attachment read or Host mutation exists in this module.

`fetchTitleLayout` checks an actual rendered line and title cell span. It returns a link rectangle plus disjoint remaining toggle rectangles. Owned SGR styling is ignored for width; OSC/cursor/control/bidi and invisible separator sequences disable the link. CJK/emoji/combining graphemes remain atomic. A clipping ellipsis is not linked; clipping without renderer source offsets requires the full authority to remain visible. Malformed/unsupported/expanded headers retain the existing row toggle.

Existing Text render wraps long titles. Preserve that behavior: give each wrapped title slice both `sourceStart/sourceEnd` (UTF-16 offsets relative to the original title), derived from the renderer's known inserted title range. The helper requires exact visible text equality to that slice and checks grapheme boundaries; it does not search arbitrary rows for URL-looking text. Link rectangles are only for title glyphs, never padding, status, body text or controls. Geometry must describe a resident visible row.

`fetchTitleActionReason`/`runFetchTitleAction` require separate explicitly confirmed open/copy capabilities, an attached permitted port, the original validator and a freshly resolved current target. Scope, key, visible-content generation, label, href and presenter source must still agree. Observation is bounded, pre-abort prevents dispatch and late rejection is observed; no opener retry occurs. An already-dispatched opener ignoring abort may still act. A timeout/changed frame is not proof that opening was revoked.

`fetchTitleGestureAction` supplies intent for an already paired completed click or explicitly URL/toggle-focused key. Plain left URL click -> open; toggle click -> toggle; plain right -> context. Drag/modified/middle gestures do not open. Tool Enter retains toggle. URL focus Enter/o -> open, c -> copy. No global shortcut or keyboard focus state is installed by this module.
